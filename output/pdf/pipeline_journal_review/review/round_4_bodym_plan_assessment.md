# Reviewer assessment of proposed retrospective BodyM evaluation

Date: 22 October 2026. This assessment is made before the coordinator fetches/reads target girth labels for the new frozen experiment. It does not claim that the dataset was never inspected by the project previously.

The reviewer endorses execution of the proposed complete Test-A experiment as meaningful independent-source human **post-perception** evidence. The proposed fixed policy selects one canonical lexicographically first available paired-photo identifier per subject from official metadata/maps, retains every selected attempt, evaluates six declared candidate outputs without choosing a winner using target labels, and uses fixed crown fractions for the silhouette-only level proxies. Source/configuration/cohort selection must be frozen before reading target girths. Record hashes, units, foreground orientation and subject/photo pair linkage.

BodyM supplies photograph-derived silhouettes and scan-defined targets; the new experiment does not exercise the paper's MediaPipe segmentation/pose stage. Fixed image-plane/model values may be evaluated as predictions of those dataset-defined targets. Differences of level/path and model remain part of observed prediction error. The results must not be called direct matched-plane measurements, tape agreement or ISO compliance. An unrounded convex occupancy diagnostic remains a diagnostic even when its numerical error against a target is tabulated.

The cohort is independently collected from the developer volunteer cases. That fact is distinct from an untouched statistical holdout. The existing `validate_bodym.py` defaults to Test-A/15, so the project cannot assert that Test-A has never informed prior evaluation or development. Disclose the new version's freeze before the agent reads labels, and describe the result as a **retrospective external benchmark**. If actual old evaluated photo/subject identifiers can be recovered, report overlap and non-overlap groups as a sensitivity analysis. Do not invent an unseen-data history from missing files or infer parameter fitting simply because an evaluation script exists.

Predeclare per-endpoint prediction errors (including signed bias and MAE/RMSE), failure/availability coverage, and paired differences for candidate/branch comparisons. Subject is the independent unit; multiple endpoint/candidate rows do not increase participant count. Any uncertainty interval or bootstrap must use a justified participant-level design and describe its conditional retrospective scope. Preserve unavailable outputs in the denominator and avoid favorable-case selection. The width/depth ellipse is an important classical baseline. Record whether profile filtering/column capping actually changes each reported torso section and its corresponding candidate estimates; a better whole-body IoU cannot establish girth benefit if reported sections are unchanged.

An appropriately executed and useful result can substantively address R02 for the retained downstream-geometry claim; it cannot automatically establish raw-RGB performance, independent prospective generalization or anatomical validity of optional waist deletion. R03/R08 require evidence that the proposed operations contribute beyond the classical baseline, not merely that some candidate predicts BodyM labels. A future suitably untouched Test-B evaluation could provide stronger confirmation, but meaningful Test-A work should proceed rather than treating all currently accessible data as unusable.

This plan assessment uses existing issue criteria. No new acceptance issue or numerical performance threshold is introduced. The final assessment will depend on the actual frozen implementation, outputs, target definitions and complete manuscript.
